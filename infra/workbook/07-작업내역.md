### 11/27 ~ 11/28 게임 검색 Elasticsearch 연동
- **스위치와 대체 경로(`#182`)**: `SEARCH_BACKEND=db|es`(기본 `db`). `es`이면 `games`·`game_aliases` 인덱스를 한 번에 검색해 찾은 `game_id`를 MariaDB 부분 일치에 합침. ES 연결 오류·2초 초과·이상한 응답이면 경고만 남기고 MariaDB로 처리. 자동완성은 ES를 쓰지 않음.
- **AI 별칭 제외**: `source=llm` 별칭은 검수 여부와 상관없이 검색에서 뺌(MariaDB·ES 모두). 근거: `game_aliases`에 `igdb` 3,712건뿐이고 `llm` 0건(11/27 조회).
- **별칭 인덱스(남현식 `#183`)**: ES `game_aliases`(MariaDB 3,712 / MongoDB 3,827 / ES 3,827, 차이는 대소문자 비교 규칙). Monstache `resume=false`.
- **backend1에서 켜서 확인**: `엘든링`·`엘든링을`·`elden rnig`가 `db`에서는 0건이었다가 `es`에서 Elden Ring이 나옴. ES `games` 1000건 = MariaDB `games` 1000건, 문서에 `game_id` 있음.
- **튜닝(`#185`)**: `cat`에 VRChat이 나오는 문제(오타 허용이 3글자부터 적용) → `AUTO:5,8` + 첫 글자 고정. 띄어쓰기가 다르면 안 나오는 문제 → 공백·기호를 뺀 비교 추가. 원인은 ES에 직접 쿼리해 확인(`AUTO` 36건 / 오타 허용 끔 0건).
- 켜는 법·확인 명령·되돌리는 법: [05-backend.md](05-backend.md) 10장.

## 4. 주요 결정과 이유
| 결정 | 이유 |
|---|---|
| 내부 VM firewalld 끔, 게이트웨이만 iptables (11/22) | 내부망은 게이트웨이 뒤에 있음, 도구 통일, 포트가 막히던 문제 해소. 대신 서비스 인증(Valkey·MongoDB·MariaDB)은 유지 |
| Valkey 저장 끔 | 캐시·세션·중복 방지 키는 사라져도 되는 것만 둠 |
| MongoDB 복제 셋 3대 | Monstache change stream 요구, 1대 장애 시 자동 전환 |
| MariaDB `skip-name-resolve`, 시간대 UTC | 접속 허용을 IP 패턴으로 관리, 저장은 항상 UTC |
| 조회는 Replica, 내 데이터는 Primary | 복제 지연 때문에 방금 쓴 값이 안 보이는 문제 방지 |
| Backend는 가격·게임 테이블에 쓰지 않음 | 쓰기는 Kafka Connect 담당, DB 권한으로 막는 것이 진짜 방어선 |
| Backend 프로세스 1개 | `/metrics` 가 워커별로 갈라지지 않게(API 사용 순위) |
| 현재가·구매 타이밍은 PC 가격 우선 | 콘솔(다나와)은 정가·할인율이 없어 섞이면 할인 표시가 사라짐 |
| 목표가 알림은 같은 가격에 한 번, 더 내려가면 다시 | 중복 메일 방지와 새 소식 전달의 균형 |
| 알림 타이머는 매시 50분, backend1만 | 수집 시각 직후에 보고, 두 서버가 중복 발송하지 않게 |
| 리뷰는 `reviews` 에만 저장(`raw_steam` 에서 제외) | 45만 건 이중 저장 해소, `raw_*` 의 TTL 14일 적용 대상 축소 |
| 검색은 ES 결과를 MariaDB 부분 일치에 **더하는** 방식, 스위치 기본 `db` (11/27) | 결과가 줄지 않고, ES가 죽어도 검색이 되며, 값 하나로 되돌릴 수 있음 |
| 별칭은 `games`에 필드를 넣지 않고 **별칭 전용 인덱스**(`game_aliases`) (11/27) | `refined.games`에 별칭이 없고 별칭은 MariaDB로만 흘렀음. 필드만 추가하면 비어 있게 됨 |
| AI(`llm`) 별칭은 검수해도 검색에 쓰지 않음 (11/27) | 팀 결정. 현재 데이터에는 `llm` 별칭이 없어 결과는 달라지지 않음 |
| 오타 허용은 5글자부터, 자동완성은 ES를 쓰지 않음 (11/27) | 짧은 단어 오타(`cat`→`chat`)가 잡음을 만듦, 자동완성은 호출이 잦아 지연 위험 |
