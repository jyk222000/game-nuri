# 네트워크 · 호스트 · 포트

> **가정값입니다.** 실제 대역·게이트웨이가 확정되면 이 파일만 고친다. 코드에는 IP를 쓰지 않는다.

## 외부에 여는 포트 (공인 IP)
- `0.222`: 80, 443 만
- `0.223`: SSH, 3000(Grafana, 로그인 필수) 만
- DB·Kafka·Kibana 포트는 **절대** 공인 IP로 열지 않는다.
