## 표기 방법 (팀 워크북과 같음)
```
# 회색 줄 : 바로 아래 명령이 하는 일
[adminc@서버이름 ~]$ 실제로 입력하는 명령
> 설정 내용, 명령 결과, mariadb 안에서 입력하는 SQL
```
> <- 명령 앞의 `[adminc@서버이름 ~]$`에서 **서버 이름을 꼭 확인**합니다. 모르면 `hostname`을 먼저 입력합니다.
> <- `<꺾쇠>` 값은 환경에 맞게 바꿔서 입력합니다. 비밀번호는 `-p`만 쓰고 입력창에서 직접 칩니다.
> <- mariadb-re(Replica)에서는 SELECT·SHOW만 합니다. 서버 레포의 `git`에는 `sudo`를 붙이지 않습니다.
