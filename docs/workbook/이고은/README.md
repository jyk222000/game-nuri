## 명령 표기
```
# 초록색 줄 대신 이 줄: 바로 아래 명령이 하는 일
[root@mariadb-pr ~]# 실제로 입력하는 명령 (mariadb-pr 에 root 로 접속한 상태)
MariaDB [gamenuri]> mariadb 안에서 입력하는 SQL
> 설정 내용이나 결과처럼 직접 입력하지 않는 줄
```
- 프롬프트의 서버 이름(`mariadb-pr`, `mariadb-re`, `kafka1`)이 지금 있는 서버인지 먼저 확인합니다. 모르면 `hostname`을 입력합니다.
- `<꺾쇠>` 값은 환경에 맞게 바꿉니다. 비밀번호는 `-p`만 쓰고 입력창에서 직접 칩니다. 문서·채팅에 쓰지 않습니다.
- mariadb-re(Replica)에서는 SELECT·SHOW만 합니다. 서버 레포의 `git`에는 `sudo`를 붙이지 않습니다.
