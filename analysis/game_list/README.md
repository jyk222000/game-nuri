# 수집 대상 게임 1,000건 선정 기준

> 작성 2026-11-23 · 선정 담당 한예찬 · 결과: [games_1000.csv](games_1000.csv), 기준 충족 현황: [selection_report.md](selection_report.md)
> 이 문서는 **최종 선정에 실제로 쓴 기준**이다. 코드는 `analysis/scripts/`에 있고, 아래 값은 코드의 상수와 같다.

## 1. 목적

수집 대상은 서비스 화면 · 분석 A1~A8 · 기능 ⑦(경고 시연)이 모두 쓸 수 있는 1,000건이어야 한다.
그래서 "인기 순 1,000건"이 아니라, **분석마다 필요한 최소 조건(쿼터)을 채우면서 인기 점수 합이 가장 큰 1,000건**을 골랐다.

| 분석 | 이 목록에서 필요한 것 |
|---|---|
| A1 할인 주기 | 가격 이력이 길고 할인 횟수가 다양한 유료 게임 |
| A2 검색 관심도 | 네이버 데이터랩에 넣을 한글 검색어 |
| A3 평론 점수 | IGDB 평론 점수가 있는 게임 |
| A4 리뷰 키워드 | 한국어 리뷰가 충분하고, 부정 리뷰도 있는 게임 |
| A5 신작·구작 비교 | 같은 시리즈의 여러 편, 오래된 게임 |
| A6 제작사 · 플랫폼 | 같은 제작사의 여러 게임, 할인 안 하는 게임 |
| A7 클리어 시간 · 장르 | `game_time_to_beats`가 있는 게임, 장르가 고르게 분포 |
| A8 콘솔 가격 | PC와 콘솔을 함께 가진 게임 |

## 2. 선정 순서

```
IGDB 평가 수 상위 12,000건 ─▶ Steam appid 있는 것만 ─▶ Steam 한국어 리뷰 200건↑
        (build_pool.py)                                     = 후보 풀 1,304건
                                                               │
                                          하드 필터 H1~H7 ─▶ 1,118건
                                                               │
                  쿼터를 만족하면서 점수 합 최대인 1,000건 (select_games.py, MILP)
                                                               │
                                       점수 순 rank 부여 ─▶ batch 1 / 2 / 3
```

### 2-1. 후보 풀 (`build_pool.py`)
- **시작점**: IGDB `games` 중 `total_rating_count > 10` 이고 출시일이 있는 게임을 `total_rating_count` 내림차순으로 12,000건.
- Steam 외부 ID(`external_games`, source 1)가 있는 게임만 남기고, 같은 appid는 평가 수가 많은 쪽 하나만 둔다.
- Steam 한국어 리뷰가 **200건 미만이면 제외**한다. Steam 응답이 200건 미만이면 0으로 주기 때문에 이 아래는 구분이 안 된다.
- 붙이는 정보: IGDB(플랫폼 · 장르 · 시리즈 · 제작사 · 모드 · 클리어 시간), Steam(한국어 리뷰 수 · 긍정률 · 무료 여부 · 한국 판매가 · 동접), ITAD(Steam 가격 이력).
- 결과는 `analysis/data/game_pool/pool.csv`(Git 제외)로 저장한다.

### 2-2. 하드 필터 (하나라도 걸리면 탈락, 첫 사유로 집계)
| 필터 | 기준 | 이유 | 탈락 |
|---|---|---|---|
| H1 | IGDB `game_type`이 본편·리메이크·리마스터·확장 본편(0, 8, 9, 10)이 아님 | DLC·번들은 가격·리뷰가 따로 놀아 분석이 오염된다 | 69 |
| H2 | Steam appid 또는 ITAD id 없음 | 게임 ID 통합 불가 | 0 |
| H3 | 출시 전이거나 출시 후 180일 미만 | 가격 이력 확보 | 22 |
| H4 | 한국어 리뷰 200건 미만 | A4 키워드 추출 · ⑤ 요약 최소량 | 0 (풀 단계에서 이미 거름) |
| H5 | IGDB 테마가 Erotic | 성인 전용 제외 | 0 |
| H6 | 유료인데 한국 판매 옵션 없음 | 판매 중단 · 지역 제한 | 74 |
| H7 | 유료인데 ITAD 가격 이력 6개월 미만 | A1 할인 주기 | 21 |

### 2-3. 점수 (0~1, 클수록 먼저 수집)
| 항목 | 가중치 | 계산 |
|---|---|---|
| 한국어 리뷰 수 | 0.35 | `log(1+x)`의 백분위 |
| IGDB 평가 수 | 0.20 | `log(1+x)`의 백분위 |
| Steam 동접 | 0.15 | `log(1+x)`의 백분위 (현재 시점 값) |
| 콘솔 플랫폼 수 | 0.15 | 최대 3개까지 `n/3` (PS5·PS4·Switch·Switch2·Xbox Series·Xbox One) |
| 할인 횟수(24개월) | 0.15 | 백분위 |

### 2-4. 쿼터 (소프트 제약)
쿼터는 **못 채워도 해가 나오도록** 부족분마다 벌점(3.0)을 주는 방식이다. 못 채운 쿼터는 `selection_report.md`에 ⚠️로 남는다.

| 쿼터 | 대상 분석 | 조건 | 목표 |
|---|---|---|---|
| Q1 | A8 · A6 · ① | PC + 콘솔 1개 이상 보유 | ≥450 |
| Q2 | A3 | 평론가 점수 있음(5건 이상) | ≥500 |
| Q3 | A4 | 한국어 긍정률 75% 미만 | ≥150 |
| Q4 | A7 · ④ | 클리어 시간 있음(3명 이상) | ≥550 |
| Q6 | A1 · A5 | 출시 2018년 이전 | ≥150 |
| Q7 | ⑦ · A2 | 온라인 게임 | ≥200 |
| Q8 | ⑦ | 온라인이면서 동접 500 미만 (경고 시연) | ≥40 |
| Q9 | – | 무료 게임 | ≤80 |
| Q10 | A2 · 다나와 매칭 | 한글 이름이 3글자 이상 | ≥600 |
| Q11 | A1 | 유료 + 24개월 할인 3회 이상 | ≥600 |
| Q12 | A6 | 유료 + 24개월 할인 0회 | ≥40 |
| Q13 | A7 | 후보가 많은 장르 상위 8개: 각 60~300건 | 장르별 |
| Q14 | A1 · A5 | 한 해에 출시된 게임이 200건 초과 금지 | ≤200 |

번호는 Q5가 비어 있다(아래 4절 참고).

추가 제약
- **시리즈(A5)**: 후보 중 3~12편인 시리즈는 통째로 넣거나 통째로 뺀다. 시리즈 40개 이상이 목표.
- **제작사(A6)**: 6편 이상 포함된 제작사 25곳 이상이 목표. 한 회사는 최대 40건.

## 3. 결과 요약 (selection_report.md 기준)
- 풀 1,304건 → 하드 필터 통과 1,118건 → 선정 1,000건
- 시리즈 2편 이상 포함 132개, 3~12편 시리즈 통째 선정은 쿼터 40개 이상 충족
- **채우지 못한 쿼터**: 후보가 모자란 항목이다.

| 쿼터 | 목표 | 실제 |
|---|---|---|
| Q4 클리어 시간 | ≥550 | 456 |
| Q10 한글 검색어 | ≥600 | 546 |
| Q12 할인 0회(유료) | ≥40 | 14 |
| Q13 Adventure / Point-and-click / Fighting | ≥60 | 50 / 49 / 46 |

이 값이 분석에 모자라면 풀(`--pool-size`)을 더 키우거나 필터를 조정해 다시 돌린다.

## 4. 처음 기준에서 바뀐 점
처음 받은 기준 문서(Claude 웹에서 만든 초안)에서 두 가지를 바꿨다.

1. **한국어 리뷰 최소 300건 → 200건.** 300건이면 하드 필터 통과가 893건이라 1,000건이 안 나왔다. 200건으로 낮추니 1,118건이 되어 1,000건을 채웠다.
2. **쿼터 Q5 "최근 12개월 신작" 삭제.** H3(출시 180일 미만 제외)과 충돌한다. 그리고 A5의 신작·구작 비교는 "시리즈 안에서의 새 작품 대 옛 작품"이라 최근 출시일이 필수 조건이 아니다. 시리즈 쿼터로 충분하다.

## 5. 알려진 한계
- **임계값은 제안값이다.** 한국어 리뷰 200건, 출시 180일, 이력 6개월, 쿼터 수치는 분석 담당자 전원이 확인한 값이 아니다. 분석을 해 보고 모자라면 조정한다.
- **온라인 여부**는 IGDB `game_modes`(멀티 · 협동 · MMO · 배틀로얄)로 추정한 값이다.
- **동접(CCU)** 은 수집 시점의 현재값이라 시간대에 따라 달라진다. 점수와 Q8에 쓰였다.
- **할인 횟수와 이력 길이**는 ITAD의 Steam 가격만 본다. 응답이 최근 약 23개월이라 "24개월 할인 횟수"가 실제로는 그 안의 값이다.
- **한국어 리뷰**는 Steam 구매 기준이다. Steam이 200건 미만이면 0으로 돌려줘서 그 아래는 비교할 수 없다.
- **A8 콘솔 가격**은 다나와에 가격이 실제로 있는지 아직 확인하지 않았다. 콘솔 플랫폼이 있다는 것만 보장한다.
- **한글 검색어**: 2글자 이하 이름은 `kw_ambiguous=True`로 표시했다(11건). 네이버 데이터랩에서 별칭이나 제외어가 필요하다.

## 7. 다시 만드는 방법
API 키는 `.env`(`TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`, `ITAD_KEY`)에서 읽는다. 중간 결과는 `analysis/data/game_pool/.cache/`에 저장되어 중단해도 이어진다.

```bash
python -u analysis/scripts/build_pool.py --pool-size 12000   # 후보 풀 (오래 걸림)
python analysis/scripts/select_games.py                      # 선정 → analysis/data/game_pool/result/
```

결과 CSV는 `.gitignore`의 `*.csv` 규칙 때문에 `git add -f`로 올려야 한다.
