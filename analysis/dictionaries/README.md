# 분석용 사전

## `review_types.json` — A4 긍정·불만 유형 (담당 이고은)
ES `reviews` 인덱스(nori)에서 뽑은 키워드를 유형으로 묶는다. 코드는 `analysis/review_types.py`.

| 구분 | 유형 |
|---|---|
| 불만(negative) 11개 | 가격·과금, 최적화·성능, 서버·운영, 번역·한글, 버그·오류, 콘텐츠 부족·반복, 조작·화면, 난이도·밸런스, 스토리·연출, 게임성·재미, 그래픽·사운드 |
| 긍정(positive) 9개 | 스토리, 그래픽·음악, 게임성, 가성비·볼륨, 콘텐츠·다양성, 같이 하기, 도전·난이도, 힐링·몰입, 한글화 |
| ignore | 유형이 될 수 없는 말(일반어·욕설·장르 이름). 건수에서 뺀다 |

- 한국어는 어간 앞부분 일치(`비싸` → 비싸다·비싸요), 영어는 소문자 단어 일치.
- 한 키워드는 한 유형에만 넣는다. 분류 못 한 키워드는 `unknown`으로 돌려주니 `unknown`을 보고
  사전을 보강한다. 11/26에 실제 ES 키워드(게임 1,000개)를 보고 한 번 보강했다
  (사전에 걸린 키워드 건수 비율: 불만 12% → 64%, 만족 10% → 40%).
- 최적화 유형 단어는 기능 ⑥ 사양표 신뢰도의 성능 키워드와 같이 쓸 수 있다.
