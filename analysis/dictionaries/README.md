# 분석용 사전

## `review_types.json` — A4 긍정·불만 유형 (담당 이고은)
ES `reviews` 인덱스(nori)에서 뽑은 키워드를 유형으로 묶는다. 코드는 `analysis/review_types.py`.

| 구분 | 유형 |
|---|---|
| 불만(negative) | 가격, 최적화, 서버, 번역, 버그, 콘텐츠 부족 |
| 긍정(positive) | 스토리, 그래픽·분위기, 게임성, 가성비·볼륨, 같이 하기 |

- 한국어는 어간 앞부분 일치(`비싸` → 비싸다·비싸요), 영어는 소문자 단어 일치.
- 한 키워드는 한 유형에만 넣는다. 분류 못 한 키워드는 `unknown`으로 돌려주니, 실제 ES 키워드
  상위 200개를 받으면 `unknown`을 보고 사전을 보강한다 (11/24 리뷰 적재 후).
- 최적화 유형 단어는 기능 ⑥ 사양표 신뢰도의 성능 키워드와 같이 쓸 수 있다.
