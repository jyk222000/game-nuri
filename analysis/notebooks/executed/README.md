# 실행 결과가 들어 있는 노트북 (발표·열람용)

`analysis/notebooks/`의 노트북은 팀 규칙(`analysis/CLAUDE.md`)에 따라 **출력을 지운 상태**로 둔다.
여기에는 같은 노트북을 **실제 데이터로 끝까지 실행한 결과**(표·차트·결론 출력)를 저장해 두어,
GitHub 웹에서 바로 결과를 볼 수 있게 한다.

| 파일 | 원본 | 실행 기준 |
|---|---|---|
| `08_A8_PC콘솔가격_실행결과.ipynb` | `../08_A8_PC콘솔가격.ipynb` | 2026-11-26, `prices_current`(mariadb-re) 추출본 |

* 실행 결과를 고칠 때는 원본 노트북을 실행해서 이 폴더에 덮어쓴다. 여기 파일을 직접 편집하지 않는다.
* 파일 하나가 1MB를 넘으면 커밋 훅(`check-added-large-files`)이 막는다. 차트가 많으면 `figure.dpi`를 낮춘다.
* 데이터(`analysis/data/`)는 Git에 올리지 않는다. 결과 숫자는 실행 시점의 DB 값이다.
